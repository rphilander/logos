## Code Investigation

When investigating logos Go code:
1. Start with `arch-search` — results include file:line for anchors
2. Use `arch-describe` for deeper context on concepts/interactions
3. Fall back to grep/glob only if arch doesn't cover the area
4. For logos language questions, use `lang-search`/`lang-describe`
5. For procedural how-to (adding ops, builtins, modules), use `guide-search`/`guide-describe`
